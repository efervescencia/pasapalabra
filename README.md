Proyecto realizado con Spring Boot y Thymeleaf

Simulación de la prueba "El Rosco" del programa de televisión "Pasapalabra"

La primera versión, la presenté en la asignatura de la ingeniería "Programación 2",
y al año siguiente los profesores lo eligieron como proyecto de la asignatura
"ingeniería del software". Era una aplicación de escritorio.

La segunda versión la realicé en php y ajax funcionando como web.

Esta versión es una mezcla y actualización de ambas, siendo web con backend java.
